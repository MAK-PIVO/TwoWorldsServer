# TW1Server

Лаунчер и панель управления для инструментов возрождения Two Worlds 1:

- общий лобби-сервер
- сервер для одиночного мультиплеера
- локальный сервер активации

* Особенности

- Один самодостаточный файл: три серверных скрипта встроены в `TW1Server.pyw`
  (base64) и разворачиваются в память при запуске. Ничего не читается из
  соседних файлов — `.pyw` можно скопировать куда угодно, и он будет работать.
- Только стандартная библиотека Python (tkinter) ставить нечего.
- Интерфейс на русском и английском, переключается на лету без перезапуска.

* Требования

- Python 3
- Windows (вкладка настроек игры использует реестр; на других ОС она сама
  отключается)

* Запуск

```
python TW1Server.pyw
```

Или двойным щелчком по `TW1Server.pyw`, если Python ассоциирован с `.pyw`.

Порт по умолчанию — `17171`.

* Данные

Конфиг и данные (`Config.ini`, `ServerData.db`, `PlayerData/`) хранятся в
`%LOCALAPPDATA%\TW1 Control Center`, а не рядом со скриптом.
